# Проект «Mesto»

Учебный проект — интерактивная страница для публикации карточек с местами, редактирования профиля и обновления аватара. РИ-430910

## Выполненные изменения и доработки

В рамках текущего этапа разработки была реализована валидация форм и настроен процесс сборки проекта.

### 1. Интеграция модуля валидации (`validation.js`)
* Реализован универсальный модуль валидации форм на чистом JavaScript.
* Добавлена динамическая проверка полей ввода в реальном времени (событие `input`).
* Настроена кастомная валидация по регулярному выражению (`pattern`) с выводом сообщений из атрибута `data-error-message`.
* Реализовано автоматическое управление кнопкой отправки формы (блокировка/разблокировка и добавление неактивного состояния).
* Создана функция `clearValidation` для сброса ошибок и состояния кнопки при повторном открытии модальных окон.

### 2. Доработка HTML-разметки (`index.html`)
* Отключена стандартная валидация браузера с помощью атрибута `novalidate` на формах.
* Добавлены HTML5-атрибуты ограничений (`required`, `minlength`, `maxlength`, `type="url"`, `pattern`).
* Для каждого поля ввода добавлены элементы `<span class="popup__error">` для корректного отображения ошибок.
* Кнопкам отправки по умолчанию заданы атрибут `disabled` и соответствующий класс неактивного состояния.

### 3. Точка входа (`index.js`)
* Вся инициализация валидации вынесена в единую точку входа.
* Создан объект конфигурации `validationConfig` с селекторами и классами элементов.
* Вызовы `clearValidation` интегрированы в обработчики открытия всех попапов.
* Соблюдена архитектура проекта: из `index.js` нет экспортов.

### 4. Окружение и сборка (Vite)
* Настроен файл `vite.config.js` для работы локального сервера.
* Проверена и выполнена итоговая продакшен-сборка проекта (`npm run build`).
